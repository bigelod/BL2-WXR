# BL2-WXR

A monocular 6DOF VR mod for flat, non-VR **Borderlands 2**, running on a
standalone headset through **WinlatorXR** and **XrApi 0.5**.

This is a WinlatorXR VR port. Read `Docs/general_wxr/CLAUDE.md` before
planning or writing any code.

Then read, in order:

1. `Docs/ClaudeCode/PROJECT_OVERVIEW.md` - the goal and what is known about the game
2. `Docs/ClaudeCode/PROJECT_PLAN.md` - the intake interview, the approach and the staged plan
3. `Docs/ClaudeCode/CURRENT_STATUS.md` - where the project actually is, and the blocker
4. `Docs/ClaudeCode/BUG_FIXES.md` - defects in the inherited scaffold, and which inherited claims to trust

`Docs/general_wxr/` is shared, game-agnostic guidance copied between the
owner's ports. Per-game findings go in `Docs/ClaudeCode/`, not in there.

`Docs/MetaAI/` is a superseded first planning pass. It may be read; it is not
current truth, and `Docs/ClaudeCode/BUG_FIXES.md` says where it is wrong.

Game install on the owner's machine: `E:\Steam\steamapps\common\Borderlands 2`.
